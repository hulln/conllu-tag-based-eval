# logos/

Institutional and funder logos used by the v5 table footer. The table references
these files by relative path (`logos/<file>`), so the folder sits next to
`comparison_table_v5.html` and the static page works without external image
requests.

## Source URLs

| Organisation | Local file | Source asset URL | Footer link |
|---|---|---|---|
| ARIS | `aris.svg` | https://www.aris-rs.si/lib/img/aris-logo.svg | https://www.aris-rs.si/ |
| CJVT UL | `cjvt.png` | https://www.cjvt.si/wp-content/uploads/2026/01/ULCJVT-Horizontal-Slo-LogoTitle.png | https://www.cjvt.si/ |
| CLARIN.SI | `clarin-si.png` | https://www.clarin.si/info/wp-content/uploads/2014/08/Clarin-SI-logo.png | https://www.clarin.si/ |
| CLARIN ERIC | `clarin-eric.svg` | https://www.clarin.eu/themes/contrib/clarin_bootstrap/logo.svg | https://www.clarin.eu/ |

## Notes

- The footer currently uses ARIS, CJVT UL, and CLARIN.SI.
- `clarin-eric.svg` is retained as an alternative to `clarin-si.png`, but is not
  referenced by `comparison_table_v5.html`.
- The CJVT source is the Slovenian-title horizontal logo published on cjvt.si.
- Source URLs were checked on 2026-06-22.
